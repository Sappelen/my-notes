## Navigation

| Shortcut | Action |
|----------|--------|
| `Alt + Left` | Navigate to parent folder |
| `Alt + Up` | Navigate to parent folder |
| `F5` | Refresh current view |

## Zoom

| Shortcut | Action |
|----------|--------|
| `Ctrl + +` | Zoom in (larger tiles) |
| `Ctrl + =` | Zoom in (larger tiles) |
| `Ctrl + -` | Zoom out (smaller tiles) |

## Selection

| Shortcut       | Action                            |
| -------------- | --------------------------------- |
| `Ctrl + A`     | Select/deselect all visible books |
| `Click`        | Select single book                |
| `Ctrl + Click` | Add/remove from selection         |

## General

| Shortcut | Action |
|----------|--------|
| `Escape` | Close popup/dialog |

## Mouse Actions

| Action | Result |
|--------|--------|
| Single click on book | Select book |
| Single click on folder | Open folder |
| Right-click | Open context menu |
| Double-click on book | Open in default application |
| Scroll wheel | Scroll grid |
| Click scrollbar track | Jump to position |
| Drag scrollbar | Smooth scroll |

## Touch Actions (Mobile/Tablet)

| Action | Result |
|--------|--------|
| Tap on book | Select book |
| Tap on folder | Open folder |
| Long press | Open context menu |
| Swipe | Scroll grid |
| Pinch | Zoom in/out |

## Tips

### Quick selection
Use `Ctrl + A` to select all visible books, then use the context menu to apply batch operations like moving or tagging.

### Fast navigation
Click on any part of the location path in the top bar to quickly jump to that folder.

### Tag filtering
Click any tag in the status bar to instantly filter to books with that tag. Click "All books" to reset.
